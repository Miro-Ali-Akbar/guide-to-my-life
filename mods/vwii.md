# The modding of my virtual Wii in my Wii U

## Games
1. Get roms from [vimm's lair](https://vimm.net/vault/Wii)
2. Use [UWUVCI](https://github.com/stuff-by-3-random-dudes/UWUVCI-AIO-WPF/releases)
3. Inject using base ROM rhythm heaven US and insert all the needed keys
4. Select the file .wbfs
5. Pack it as a WUP installable
6. Place the files in ~/install
7. Its in home as a virtualconsole game
